# Requerimientos funcionales

## Buscar videojuegos por nombre

La aplicación debe permitir buscar videojuegos por nombre exacto y por coincidencia parcial.

## Listar todos los videojuegos

La aplicación debe permitir visualizar el listado completo de videojuegos disponibles.

## Filtrar videojuegos

La aplicación debe permitir filtrar videojuegos por género, plataforma y rating mínimo.

## Ver detalle de un videojuego

La aplicación debe permitir consultar los detalles de un videojuego seleccionado.

## Comparar dos videojuegos

La aplicación debe permitir seleccionar y comparar dos videojuegos a partir de la información disponible.

## Crear nuevo ranking

La aplicación debe permitir generar un ranking de videojuegos según su rating, ordenando los resultados de mayor a menor o de menor a mayor. También debe permitir indicar la cantidad de videojuegos que se desea incluir en el ranking.

## Ver videojuegos relacionados

La aplicación debe permitir buscar un videojuego y visualizar otros videojuegos relacionados a través de las conexiones establecidas en el grafo, utilizando el algoritmo BFS para realizar el recorrido.

## Ver camino más corto entre dos videojuegos

La aplicación debe permitir seleccionar dos videojuegos y encontrar el camino con menor cantidad de aristas entre ellos, utilizando BFS. Si no existe un camino entre ambos videojuegos, debe informar al usuario.

## Explorar conexiones entre videojuegos

La aplicación debe permitir seleccionar un videojuego y explorar los videojuegos conectados a él mediante un recorrido en profundidad (DFS).
